# TurnChain Screenshot Gallery

This directory contains visual captures of the TurnChain application on Base Sepolia.

### Recommended Demo Screenshots:
1. `01_game_lobby.png` — Main Game Lobby showing Open Games, My Matches, and Quick Jump ID bar.
2. `02_waiting_invite.png` — Game Board in Waiting state showing Player 1 host, direct share link, and invite banner.
3. `03_active_match.png` — Live 7x6 Connect Four board during turn-by-turn play with column hover indicators and 24h timeout countdown.
4. `04_winner_celebration.png` — Victory state with winner badge and celebratory confetti.

### How to Capture Screenshots for Presentation:
1. Run `npm run dev` in `frontend/` and open `http://localhost:5174/`.
2. Connect your browser wallet on Base Sepolia.
3. Use Windows Snipping Tool (`Win + Shift + S`) or browser developer tools to capture the 1080p full-window view.
